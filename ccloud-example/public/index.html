cCloud Developer Documentation

          
cCloud uses isolated storage folders. Each user has full write/read access to their sandbox path under users/{uid}/data/.


          
Standard Client Setup

          
Import and initialize the Client SDK inside your script tag:

          
<script src="https://cloud.craftedgamz.com/client-sdk.js"></script>


          
Using the Client SDK

          
Create a class instance and initialize your worker-hosted cCloud service:

          
const ccloud = new CCloud({
  workerUrl: 'https://cloud.craftedgamz.com'
});

await ccloud.init();
await ccloud.signInWithEmail('user@example.com', 'password');

// Create data collection document
await ccloud.setData('settings', { theme: 'dark' });

// Read data collection document
const data = await ccloud.getData('settings');

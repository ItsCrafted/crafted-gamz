v13.0.0

Glassmorphism Effect (iOS 26)

We have implemented a new glassmorphism effect across the UI, taking inspiration from Apple's iOS 26. You can see this effect on this page as you read.

Backgrounds

If you have ever seen Crafted Gamz Version 9 or 10, you will remember our classic AI backgrounds. We have brought that back, filtered through them, and added even more incredible images. These images cycle daily.

Games Page

We have removed the All Games page and filtered through the games to find the best ones. we then added them to the main games page. Some of these had trigger words fo GoGuardian, so we have obfuscated the elements as a shot at getting around this.

Search Page

We have removed out old broken pr0xy, and replaced it with a un-proxified search engine for when Google is blocked.

Apps Page

We have removed our broken apps page and replaced it with a index of external projects.

Planned maintenance every morning for 30 seconds between 8:00 and 9:00 Mountain Daylight Time (MDT).

# Crafted Gamz v7

This is v7 of Crafted Gamz, a much bigger version of the web based game loader. This version changes the layout into a larger main page, adds a lot more games, switches the game folders to shorter `GF` names, and adds image backgrounds for the themes.

## What's new in v7

- Updated the project status system to use `crafted-gamz-v7`.
- Reworked the main page into `Crafted Gamz | Main Page`.
- Added a much larger game list with new thumbnails.
- Switched game folders to numbered `GF` folders and thumbnails to `GI` images.
- Added background images for the themes in the new `themes` folder.
- Added `settingicon.js` as a local Font Awesome/settings icon script.
- Kept the web app manifest.
- Kept the `*` key shortcut that sends the browser to Google Drive.
- Added labels for games that need wifi and games that are original/bundled.
- Added/kept shortcut links for Google Unblocked, Windows 11, Crazy Games, Poki, 3kho, Now.gg, and Asteroid V3.

## Notes

This is still an older version, so some links may be unfinished. The navbar still points to Minecraft, Scratch Games, and Settings folders, but those folders do not appear to be included in this branch.

The theme system now uses image backgrounds, but the old theme switcher path is still referenced even though the old Settings folder is missing.

Some game names and labels may have spelling mistakes because this was still an early version of the bigger launcher rewrite.

Most games are still plain HTML, CSS, and JavaScript, so the site can run directly in a browser without a build step.

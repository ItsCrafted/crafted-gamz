# Crafted Gamz v8

This is v8 of Crafted Gamz, also shown in Settings as version 8.0. This version builds on the big v7 launcher rewrite and adds more polish around loading, settings, legal info, and extra sections.

## What's new in v8

- Updated the project status system to use `crafted-gamz-v8`.
- Added the Settings folder back.
- Added a Settings page with version info, game count, bug fix/antiblock count, theme selection, and legal documents.
- Added `legaldocs.txt` for Terms of Service and Privacy Policy info.
- Added `launch.mp4`.
- Added `uloader.html`, a loading/launcher page that plays the launch video before opening the loader.
- Added `ovl.html` for the overlay-style iframe page.
- Added a Movies And TV page/link.
- Added Tanuki Sunset.
- Added more `.5` alternate pages for several games.
- Added `favicon2.png`.
- Kept the image theme backgrounds from v7.
- Kept the `GF` game folder system and `GI` thumbnail system.
- Kept the web app manifest.
- Kept the `*` key shortcut that sends the browser to Google Drive.

## Notes

This is still an older version, so some links may be unfinished. The navbar still points to Minecraft and Scratch Games folders, but those folders do not appear to be included in this branch.

Settings lists this release as version 8.0 with 62 games, 4 bug fixes/antiblocks, and release number 8.

Some text has encoding issues in this archive, so a few icons and special characters may not display correctly unless the files are cleaned up.

Most games are still plain HTML, CSS, and JavaScript, so the site can run directly in a browser without a build step.

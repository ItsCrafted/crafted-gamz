# Crafted Gamz v9

This is v9 of Crafted Gamz, also shown as Crafted Gamz IX on the new opening screen. This version changes the way the site starts, adds more settings, and makes the main loader cleaner by moving extra items into other sections.

## What's new in v9

- Updated the project status system to use `crafted-gamz-v9`.
- Changed `index.html` into a full-screen video splash page.
- Added `load.mp4` for the new launch video.
- Added `timeloader.html`, which loads the main game page in an iframe.
- Moved the main game list into `gameloader.html`.
- Added optional clock support with 12-hour and 24-hour settings.
- Added time tracking in localStorage for time spent in the loader.
- Added many new theme backgrounds.
- Added Custom theme support with instructions for adding `custom.jpg`.
- Added a Miscellaneous section.
- Added Crafted AI.
- Added a note on the main loader that missing items can be searched through Google Unblocked.
- Added a new label for games that only work on home wifi.
- Kept Movies And TV, Google Unblocked, Tanuki Sunset, and the overlay page.
- Kept the `*` key shortcut that sends the browser to Google Drive.

## Notes

This is still an older version, so some links may be unfinished. The Minecraft link is still on the loader, but the `games/minecraft` folder does not appear to be included in this branch.

The Settings page now has many more theme options: Kelp, The Enforcer, Black Pyramid, Mountains, Stellar Desert, Jungle, Savanna, Volcano, Autumn Forest, Tundra, Canyon, and Custom.

Some icons and special characters may display incorrectly in this archive because of encoding issues.

Most games are still plain HTML, CSS, and JavaScript, so the site can run directly in a browser without a build step.

# Crafted Gamz v3

This is v3 of Crafted Gamz, a web based game loader made to keep a bunch of browser games in one place. This version keeps the simple launcher style from v2, but adds more games, more themes, and a cleaner settings folder so the site is easier to use.

## What's new in v3

- Added a new favicon for the site.
- Moved Settings into the main root folder so the settings button works normally.
- Added more theme options:
  - Light
  - Dark
  - Sunset
  - Sky
  - Nuclear
  - Ocean
  - Poison
- Added Cookie Clicker with a warning page before launching it.
- Added the Chrome Dino Game.
- Added Osu as a TurboWarp packaged game.
- Added a Retro Emulation button on the main loader.
- Added new thumbnails for the new games.
- Updated the project status system to use `crafted-gamz-v3`.
- Removed the Minecraft button from the main navbar.
- Hid the Atticus Badlands navbar button for now.

## Notes

This is still an older version, so some stuff may be unfinished or buggy. Tic Tac Toe is still marked as very buggy, and the Retro Emulation button is on the loader even though the matching game folder may not be included in this branch.

Cookie Clicker is an older downloadable version that allows mods, so it has a warning page before opening. Back up saves if you use it.

Most of the games are still plain HTML, CSS, and JavaScript, so the site can run directly in a browser without a build step.

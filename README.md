# Crafted Gamz

![Crafted Gamz](./README-assets/hero.png)

Crafted Gamz is a multi-mode browser platform that combines browser games, proxy tools, AI features, media, apps, and a desktop-style environment into a single experience.

It is designed to give users one place where they can play, browse, personalize their setup, and return to a workspace that still feels familiar.

## Accounts and Continuity

Crafted Gamz includes full account support and is designed to provide a persistent experience rather than a one-time session.

Users can sign in with:

- Google
- GitHub
- Email and password

Accounts help preserve continuity across the platform. Depending on the mode, sign-in can retain and sync items such as:

- preferred environment
- onboarding progress
- bookmarks
- pins
- open tabs
- settings and local preferences
- app and desktop-related state

Guest access is also available for users who want to get started quickly, but the broader platform is clearly built around long-term use and returning identity.

## The Three Modes

Crafted Gamz is organized around three primary environments, each serving a different style of use.

### Desktop

Desktop mode is the most expansive environment in Crafted Gamz. It is designed to feel like a lightweight browser-native operating system, with a presentation that strongly echoes macOS.

It includes:

- a desktop layout with windows
- a dock for pinned and running apps
- a launcher for opening content quickly
- an app store for browsing and installing apps
- installable game, internet, and utility apps
- fullscreen, minimize, restore, and multi-window behavior
- top-bar widgets for account status, platform stats, network state, and weather

This mode is more than a themed landing page. It is intended to function as its own environment inside the broader platform.

One of its most notable features is the built-in AI assistant, which functions much like a lightweight Jarvis-style system helper. In addition to conversation, it can interact with the desktop itself and assist with tasks such as:

- listing installed apps
- retrieving apps available in the store
- installing apps
- opening apps
- closing and minimizing windows
- pinning and unpinning apps
- opening settings or the app store

That integration gives desktop mode a stronger sense of identity and makes it feel more like an active workspace than a standard launcher.

### Website

Website mode is the most traditional face of Crafted Gamz. It is the mode that most closely resembles a classic unblocked games and proxy site, while still offering a broader range of features than that label usually implies.

This mode includes:

- the main landing experience
- a large browser game library
- app shortcuts and wrappers
- AI chat
- music and movie pages
- virtual machine pages
- a search and proxy section
- platform statistics and top-game tracking

It is the most immediate and familiar mode. Users can quickly move from the home page into games, apps, search, or other tools without needing to learn a more advanced interface first.

What distinguishes it is that it extends beyond the traditional game-directory model by combining that familiar structure with account features, media, AI, and built-in proxy access.

### Browser

Browser mode turns Crafted Gamz into a full proxy browser environment rather than a single search-based utility.

It includes:

- tabs
- back and forward navigation
- reload and home controls
- a full address bar
- bookmark support
- a bookmarks bar
- account and settings pages
- connection details
- server and region switching
- local internal pages through `cg://` shortcuts
- theme switching with dark and light modes
- background presets such as Minimal, Aurora, Dusk, Ember, Ocean, Ash, and Rose

Its internal browser pages cover areas such as:

- games
- movies
- AI
- music
- VMs
- about
- settings
- account

This mode is especially effective because it allows the proxy experience to feel like a real browsing environment rather than a temporary tool. It also supports account-backed continuity for important browser state, including bookmarks, pins, and saved tabs.

For users who want Crafted Gamz to function as a primary browsing workspace, browser mode is the clearest expression of that goal.

The browser also has its own visual system. Users can switch between dark and light themes and combine those modes with background presets to change the overall feel of the environment.

## Proxy Capabilities

Proxy access is a central part of Crafted Gamz's identity.

Across the platform, proxy-focused browsing is supported through:

- Ultraviolet
- Scramjet
- Wisp-backed connections
- a dedicated proxy search flow
- the full browser-mode proxy environment

This means Crafted Gamz is not limited to games or static content. It is also built to make the wider web accessible from within the platform itself.

## More Than a Game Site

Crafted Gamz can reasonably be described as a game site, because games remain a major part of its offering. The project contains more than one hundred game pages across its mirrored environments, along with app wrappers, media sections, AI tools, and installable desktop content.

What makes it distinctive, however, is that it consistently extends beyond that category.

It is simultaneously:

- a classic unblocked-games hub
- a proxy platform
- a custom browser environment
- a browser-native desktop
- a personal web workspace

That combination is what gives Crafted Gamz its broader identity.

## Why It Stands Out

- It includes account support, allowing the experience to persist over time.
- It offers three distinct modes instead of a single flat interface.
- Desktop mode comes close to a lightweight browser operating system.
- Browser mode functions as a true proxy browsing environment rather than a simple launcher.
- Website mode preserves the fast, familiar feel of a traditional UBG and proxy site.
- AI is integrated into the platform experience rather than added as a disconnected extra.

## In Short

Crafted Gamz is a platform built around continuity.

Users can sign in, choose an environment, save their setup, browse through a proxy, install apps inside a desktop-style shell, use an assistant that can interact with the system, and still return to the more familiar game-site experience when they want it.

That is what makes Crafted Gamz more than a standard browser games site.
